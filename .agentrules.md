# Agent Context & Engineering Rules

This repository enforces strict CI/CD and contribution workflows. Any AI agent operating within this codebase must adhere to the following rules:

1. **Branch Off `dev`**: Always branch off the staging branch (`dev`) for new features or bug fixes.
2. **Parallel Branches & No Direct Pushes**: Keep features in dedicated kebab-case branches (`feat/...`, `fix/...`, `chore/...`). Never push directly to protected branches (`main`, `dev`). All changes must be submitted via pull requests.
3. **Mise Parity First**: Run `mise run <task>` (e.g. `mise run lint`, `mise run test`, `mise run build`) to execute checks locally. Never bypass git hooks or execute ad-hoc commands when a mise task exists.
4. **Cross-Platform Compatibility**: Add platform-specific dependencies directly to `devDependencies` or appropriate manifests if required to keep local git hooks and mise tasks executable on all developer OSes (Windows, Linux, and macOS).
5. **Continuous Verification**: Ensure all tests and linters pass cleanly before proposing changes or submitting pull requests.
