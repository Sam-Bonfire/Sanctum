# Agent Context & Repository Rules

## Rule 1: Branching Model
- Always branch off the staging branch (`dev`).
- Never push directly to protected branches (`dev`, `main`).

## Rule 2: Parallel Workflows & VCS
- Keep features isolated in topic branches.
- Use native Jujutsu (`jj`) commands (`jj commit`, `jj describe`, `jj git push`) for version control.

## Rule 3: Task Parity via `mise`
- Always execute operations via `mise run <task>` (e.g. `mise run lint`, `mise run test`, `mise run build:android`).
- Do not bypass linter or git verification hooks.

## Rule 4: Multiplatform & Flavor Integrity
- Sanctum supports 9 white-label religious flavors (`islam`, `christianity`, `hinduism`, `buddhism`, `jewish`, `sikhism`, `jainism`, `shinto`, `taoism`).
- All code changes must maintain cross-platform compatibility across Android, iOS (macOS), and Web (WasmJS).
